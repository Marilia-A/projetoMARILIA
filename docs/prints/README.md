# Prints das telas do MARILIA

Tirados em 15/11/2026, depois do Bloco 12 (versão v1.5), em 2560 × 1600 (janela de 1280 × 800 em tela de alta resolução).

- As telas de aluno e de administração foram feitas com uma API local de teste (professor e aluno de demonstração).
- O tutor (11) e o painel do professor (21 e 22) usam a API na nuvem, com as contas de teste criadas pela autora, para mostrar uma resposta real da IA e dados reais de progresso.
- Nas brincadeiras (03 a 07), o robô já foi clicado: lâmpada acesa, semáforo no amarelo, botão apertado, noite com LED aceso e alarme tocando.
